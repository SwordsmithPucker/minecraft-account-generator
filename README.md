Fast Minecraft Java Edition account generator. Creates valid Mojang/Microsoft accounts with username customization and skin support.

## Features

- ✅ Microsoft account generation
- ✅ Custom username support
- ✅ Skin upload on generation
- ✅ Proxy support for mass generation
- ✅ Account validity checker built-in
- ✅ Export to MFA/NFA formats
